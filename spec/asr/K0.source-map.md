# K0 Resolved ASR Source Map

Status: `DRAFT`

The published K0 provenance artifact conforms to
`K0.source-map.schema.json`. It maps resolved-ASR JSON Pointer objects to exact
half-open ranges in the original manifest-closed UTF-8 byte streams.

Normative invariants:

1. source inventory is exact, unique, ASCII-sorted, and content-addressed;
2. `asr_hash` binds the map to the exact canonical semantic ASR;
3. every pointer resolves to one object in the paired ASR;
4. every source-derived ASR object is covered exactly once in ASR preorder;
5. identity records and derived contract targets are not source nodes;
6. source ranges are nonempty UTF-8-boundary intervals;
7. synthetic ranges are empty insertion points;
8. entries use their enclosing module's source and remain inside the nearest
   mapped ancestor; and
9. source-map content never enters semantic ASR, contract, or Core hashes.

LCP-0003 and draft LDR-0007 define the complete proposed boundary. Field
identity and ASR-to-Core lowering are not part of this artifact.
