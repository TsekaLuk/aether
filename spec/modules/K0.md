# K0 Module and Name Resolution

Status: `DRAFT`

1. One source file declares exactly one module path.
2. A package manifest maps a module path to exactly one source file.
3. K0 has no wildcard imports, prelude injection, runtime module initializer, or
   conditional name lookup.
4. Public symbols are keyed by `(package_id, module_path, declared_name)`.
5. Public declarations cannot overload a name by type or arity.
6. Name resolution is completed before type checking and is serialized in ASR as
   a stable symbol identifier.
7. A reference to zero or multiple visible declarations is rejected.
8. Module-level constants are evaluated by the total K0 constant subset. Their
   evaluation order is not observable.

The import/package grammar and complete constant evaluator remain `OPEN`; this is
a G0 blocker because they affect source acceptance and `syntax_hash`.
