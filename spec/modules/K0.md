# K0 Module and Name Resolution

Status: `DRAFT`

1. One source file declares exactly one module path.
2. A package manifest maps a module path to exactly one source file.
3. K0 has no wildcard imports, prelude injection, runtime module initializer, or
   conditional name lookup.
4. Public symbols are keyed by `(package_id, module_path, declared_name)`.
5. Public declarations cannot overload a name by type or arity.
6. Name resolution is completed before type checking and is serialized in ASR as
   a stable symbol identifier.
7. A reference to zero or multiple visible declarations is rejected.
8. Module-level constants are evaluated by the total K0 constant subset. Their
   evaluation order is not observable.
9. K0 has no import declaration. An unqualified symbol path searches only the
   current module. A qualified path maps all components except the final declared
   name to a module path in the same package.
10. Type, value, and contract labels occupy separate namespaces. A nominal type
    and one of its variants may be named in value position; resolution fixes the
    constructor kind before type checking.
11. A lifetime label is scoped to one function signature. Equal spelling in the
    same signature denotes one relation ID; labels do not resolve across items.
12. Allocator brand paths resolve only against the target manifest. Source code
    cannot declare or alias a brand.

## Package manifest

The package manifest conforms to `manifests/package.schema.json`. Its module map
is complete: every source file belongs to exactly one declared module, every
declared module has one normalized relative source path, and undeclared source
files cannot enter the package hash. Module paths and normalized paths are
unique. K0 has no dependency list, build script, feature condition, environment
substitution, or generated-source hook.

## Symbol identity

For package ID `P`, module path `M`, namespace `N`, declared name `D`, and item
kind `K`, the stable symbol identity is:

```text
sym:hex16(sha256("aether-k0-symbol\0" || P || "\0" || M || "\0" ||
                 N || "\0" || D || "\0" || K))
```

`hex16` is the first 16 lowercase hexadecimal digits. A hash collision is
`SYMBOL-ID-COLLISION`; implementations must compare the full identity tuple and
must not select one declaration.

## Constant evaluation

Module constants use `contract_expression`. References form a directed graph.
Resolution rejects cycles with `CONST-CYCLE`, then evaluates nodes in the unique
lexicographic topological order induced by stable symbol identity. Arithmetic is
exact mathematical arithmetic followed by the declared result-type range check.
Evaluation emits no runtime event and cannot read target state except the fixed
width of `usize` and `isize` from the content-addressed target manifest.
