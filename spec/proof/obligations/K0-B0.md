# K0 B0 Obligation Generation

Status: `DRAFT`

B0 is mandatory and solver independent. It establishes type, initialization,
move, borrow, allocation-brand, error-exhaustiveness, and mandatory numeric-range
facts. It cannot rely on user contracts marked `DECLARED_UNPROVEN`.

Each obligation has this canonical identity:

```text
obligation_hash = sha256(
  spec_lock_hash || rule_id || normalized_core_node || normalized_context
)
```

The checker result is one of `PROVED_BY_B0`, `REJECTED(counterexample)`, or
`INTERNAL_INCOMPLETE`. `INTERNAL_INCOMPLETE` blocks artifact production and is not
reported as a source error.

The complete normalized context encoding and proof-object format remain `OPEN`.
