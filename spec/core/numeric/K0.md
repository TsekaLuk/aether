# K0 Numeric Semantics

Status: `DRAFT`

K0 integers are `u8/u16/u32/u64`, `i8/i16/i32/i64`, and target-defined
`usize/isize`. Integer values are mathematical integers constrained by the range
of their type.

## Operations

- Plain `+`, `-`, and `*` are exact operations. They are accepted only when B0
  proves the result remains in range on every reachable path.
- `checked_add/sub/mul` returns `Result<T, ArithmeticError>`.
- `wrapping_add/sub/mul` computes modulo `2^bits`.
- `saturating_add/sub/mul` clamps to the type minimum or maximum.
- Division by zero and an invalid shift count must be statically excluded or use
  an explicitly checked operation returning an error value.
- Signed division overflow (`MIN / -1`) follows the same rule as other overflow.
- Integer conversion is explicit and chooses exact, checked, wrapping, or
  saturating behavior.

## B0 range domain

The mandatory minimum abstract domain is intervals over exact integers with
branch refinement for comparisons against typed constants. Joins take the convex
hull; loops iterate to a deterministic fixed point using a specified widening.
The exact widening thresholds and rejection diagnostic are `OPEN`, so numeric B0
is not yet G0-complete.

Floating point is not in the v0.4 K0 frozen subset.
