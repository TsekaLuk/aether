# K0 Object and Memory Model

Status: `DRAFT`

## Objects and places

```text
Object = (AllocationId, Path, Type, StorageDuration, InitState)
Reference = (AllocationId, Path, Permission, Lifetime)
Permission = SharedRead | ExclusiveReadWrite
```

`AllocationId` is unique for an execution and is not a numeric address. `Path`
selects a named field or array element within an allocation. A reference carries
the provenance of its allocation and cannot be fabricated from an integer.

## Storage durations

- Static constants live for the execution and contain no runtime initializer.
- Frame allocations live until their owning frame exits.
- Dynamic allocations live from successful `alloc` to matching `dealloc`.
- Dropping an affine owner does not end dynamic storage; it produces an explicit
  leak diagnostic and makes the allocation unreachable in safe K0.

## Initialization

An object or supported named field is `Initialized` or `Uninitialized`. Reads,
borrows, moves, and deallocation of uninitialized storage are rejected. Structure
field state is tracked independently. Array and slice elements are treated as one
aggregate state for static partial-move purposes in K0.

## Allocator brands

Each target-declared allocator has a nominal brand `A`. The static type
`Allocator<A>` and every `Own<T,A>` include that brand. Successful allocation also
stores it in the dynamic allocation record. Static brand equality prevents normal
cross-domain deallocation; the runtime consistency check protects against a
defective lowering or corrupt external implementation and becomes translation
evidence, not a new safe-program failure path.

The reference target declares a maximum capacity for each brand. A conformance
vector binds the concrete capacity in its initial target state, and that binding
is part of the vector hash. A conforming executor must reject a vector whose
capacity exceeds the target maximum or whose allocator name/brand pair is absent
from the target description.

## Representation

Normal structure and enum layout is not an external interface. Padding is not a
field value and cannot be read, compared, hashed, or exposed by safe K0. Explicit
ABI representation is outside the stable K0 surface and must not be inferred from
the reference target.

## Fault boundary

Use-after-move, use-after-deallocation, double-deallocation, invalid borrow, and
cross-brand deallocation are static rejections in a conforming K0 front end. The
transition-vector executors deliberately model them as deterministic rejections
to test the state rules; this does not turn them into permitted runtime behavior.
