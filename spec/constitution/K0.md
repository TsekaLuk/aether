# K0 Semantic Constitution

Status: `DRAFT`  
Language version: `0.4.0-draft`  
Core layer: `K0`

K0 is a sequential, deterministic, safe executable core. It exists to establish
the smallest reusable base for explicit resources and machine-checkable behavior.

## Invariants

1. Expression and argument evaluation is left to right.
2. Every non-`Copy` value has at most one owner.
3. A moved or uninitialized place cannot be read, borrowed, moved, or deallocated.
4. Shared borrows exclude mutation and moves; an exclusive borrow excludes every
   other access path that overlaps the borrowed place.
5. Dynamic storage is created only by `alloc` with an explicit `Allocator<A>`.
6. `Own<T, A>` is affine and cannot be copied.
7. `dealloc` accepts only an allocator with the same unforgeable brand `A`,
   consumes the owner, invalidates the allocation, and returns the contained `T`.
8. Scope exit does not execute user code or recursively release resources.
9. Recoverable failure is a sum value. No exception, unwind, or implicit error
   propagation exists in K0.
10. Safe K0 has no undefined, unspecified, or silent implementation-defined
    behavior. Target variation is explicit and content-addressed.

## Exclusions

K0 does not expose user `unsafe`, FFI, effects, capabilities, concurrency,
user-defined generics, traits, closures, dynamic dispatch, implicit destruction,
or proof assumptions. Contracts are parsed and checked for well-formedness but
remain `DECLARED_UNPROVEN`.

## Status rule

This constitution constrains every lower artifact. The current package remains
`DRAFT` until the formal rules, conformance coverage, independent executors, and
mechanized metatheory satisfy the G0 gate.
