# Security Policy

## Current status

Aether is a pre-G0 research specification. It is not approved for production,
safety-critical, security-critical, or adversarial workloads.

## Reporting

Do not open a public issue for a vulnerability that could compromise unpublished
research, credentials, or future users. Use GitHub private vulnerability reporting
when enabled, or contact the repository owner through the private repository.

Reports should identify the affected Rule IDs, the smallest Core transition or
source example, the violated invariant, and whether the issue concerns the
specification, conformance oracle, executor, validator, or trust boundary.

No security guarantee is made until the relevant rule is stable and its proof,
conformance, implementation mapping, and residual assumptions are published.
